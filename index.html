Why this is free and unlimited

Voice in uses the speech recognition built into your browser (Web Speech API). Voice out uses your browser's speech synthesis. Both run on your device's browser — there is no account, no API key and no per-minute billing, so talking never costs anything and never runs out.

The brain is an open, keyless text model served by Pollinations. No sign-up, no card, no token. Because it is a shared public service it allows about one reply every 45 seconds — the tutor shows a countdown and answers on its own once the slot is free, so you never lose a question.

Sarvam AI: their voice APIs are excellent and Indian-language first, but they require an API key with billing attached, so they are not “100% free and unlimited” for a public app. That is why this tutor uses the browser's own voice stack instead — nothing to pay, ever.

Privacy: your chat is saved only in this browser's local storage. Nothing is uploaded anywhere except your question text, which goes to the model to generate an answer.

Optional: use your own free API key for faster replies

Only if you already have a key. It is stored in this browser only and sent straight to that provider. Groq and OpenRouter both give free keys without a card; Sarvam gives free credits and Indian-language models.

Best on Chrome or Edge on desktop and Android. iPhone Safari supports speaking answers; typing always works.
